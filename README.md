# Ծախսերի հետեւող

Պարզ վեբ հավելված՝ ամսվա ծախսերը կատեգորիաներով հետեւելու համար։ Տվյալները պահվում են բրաուզերի localStorage-ում։

## Աշխատացնել

```bash
npm install
npm run dev      # տեղական սերվեր
npm run build    # արտադրական տարբերակ՝ dist/ թղթապանակում
```

Պահանջվում է Node.js 18+։

## Կառուցվածքը

- `index.html` — էջի կմախքը
- `src/main.js` — ինտերֆեյսի տրամաբանությունը
- `src/store.js` — կատեգորիաներ եւ տվյալների պահպանում
- `src/style.css` — ոճերը (բաց/մութ ռեժիմ)

## GitHub Pages

Տեղադրելու համար `npm run build`, ապա `dist/`-ի պարունակությունը հրապարակիր։
